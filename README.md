# Open Minis Bridge

Telegram에서 허용되는 HTTPS 링크를 iPhone의 `Minis에게 프롬프트 보내기` 단축어 실행 URL로 연결하는 정적 페이지입니다.

## 사용 형식

`https://hodumarujoa.github.io/open-minis-bridge/?text=<percent-encoded-prompt>`

다른 단축어 이름을 지정해야 할 때는 `&name=<percent-encoded-shortcut-name>`을 덧붙입니다.

비밀번호, 토큰, 인증코드 등 비밀값은 링크에 넣지 않습니다.
